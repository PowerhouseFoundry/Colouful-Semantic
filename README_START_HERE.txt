COLOURFUL SEMANTICS - V6

Open index.html in Chrome, or publish the full folder to Firebase Hosting.

HOME: Cooking, Community, Jobs, Home, College, Custom.
Each built-in category has 10 photograph activities, all prepared for you to upload photos.

GALLERY: Pictures only. A green border and tick mean the learner has completed that activity correctly using Check.
No titles appear below photograph tiles. The section heading appears once, in the top header.

BUILDER: The photograph is centred at the top. Coloured SQUARE boxes are empty until symbols are dropped onto them.
Symbols can be dragged with mouse, touch or pen and visibly follow the pointer; click/tap also selects a symbol.
The sentence appears in large writing. Read, Clear and Trace work in the same sentence panel. Trace changes the sentence panel to a writing surface, not a new panel.
Teacher controls can toggle colours, change choice counts and upload photos, add symbols and custom activities.
Teacher -> Reset progress clears ONLY green picture completion markers, after confirmation. It does not delete photos or custom activities.

IMPORTANT: Images in the symbols folder are PLACEHOLDERS, not Widgit symbols. Replace PNG files using the SAME filenames to keep links working.
The app stores user-added photographs, symbols, custom activities and completion progress locally in this browser/device. These do NOT automatically sync to another device.
Use the Backup control to export media before changing devices, clearing browser data or making major changes.
No real learner personal information should be uploaded.


PHOTO FOLDERS (VERSION 7)
-------------------------
The photos folder includes five category folders and 50 real JPEG placeholder files.
Each file is ALREADY linked to the correct activity in the app.
For example: photos/cooking/cooking_01.jpg is the first Cooking picture.
To replace a photo, export your new image as JPG/JPEG, rename it EXACTLY to the placeholder filename, and overwrite the existing JPG in that folder.
Do not change the folder names or filenames. Keep the entire app folder together when uploading to hosting.
PHOTO_FILENAMES.csv lists all 50 file names and the suggested scene for each.
You may use any photo dimensions; landscape images around 1200 x 800 pixels are a good starting point.
If an activity was previously given a photo using the app's Photos upload button, the locally uploaded version will take priority over the folder file on that device. Use a fresh browser profile or remove that stored upload to see the folder version.
Photos in the folders are shared when you deploy the full app folder to Firebase Hosting; uploads added through the teacher panel remain local to that device.
Custom activities still use the teacher uploader and are not automatically saved into these folders.
